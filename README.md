# 🦁 めざせ、全国制覇！！！ どうぶつえんビンゴ 🐘

全国の動物園をめぐるビンゴWebアプリです。  
行ったことのある動物園をクリックして赤〇を付け、一列揃うと「BINGO!!」の演出とお祝いが表示されます。

## 🌟 特徴

- **2つのコース**:
  - 🐣 **初級編（7×7 / 全49園）** : 全国のメジャーな有名動物園を厳選
  - 🦁 **上級編（11×11 / 全121園）** : 全国の動物園を網羅したマスター向け
- **演出機能**:
  - マス目をクリックするとポンッと手書き風の赤〇スタンプ
  - 縦・横・斜めの一列が揃うと華やかなポップアップ、ファンファーレ効果音、紙吹雪
  - ビンゴになったラインのマスがゴールドにハイライト
- **便利機能**:
  - 💾 **画像保存**: マークした状態の画像をワンクリックで高解像度ダウンロード
  - 🔄 **リセット**: チェック状態のクリア
  - 🔊 **効果音ON/OFF**: 音の切り替え
  - 📱 **レスポンシブ対応**: スマートフォン・タブレット・PCどこでも快適に操作可能
  - 🔄 **進捗自動保存**: ブラウザを閉じてもチェック状況を維持（localStorage）
